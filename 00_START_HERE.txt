🚀 QUICK START (5 MINUTES):

  Step 1: Setup Environment
    $ python3 -m venv venv
    $ source venv/bin/activate
    $ pip install fastapi uvicorn streamlit anthropic pydantic httpx langgraph langchain
    $ export ANTHROPIC_API_KEY=your_api_key_here

  Step 2: Start FastAPI Server
    $ python -m uvicorn api.main:app --reload --port 8000

  Step 3: Start Streamlit UI (in another terminal)
    $ streamlit run ui/app.py

  Step 4: Open Browser
    → http://localhost:8501

  Step 5: Submit Application
    → Fill out the loan application form
    → Click "Submit Application"
    → View decision with reasoning

🎯 DECISION LOGIC:

  Risk Scoring:
    - Employment Risk: 15% weight
    - Income Stability: 20% weight
    - Credit Risk: 35% weight
    - DTI Risk: 25% weight
    - Loan Amount: 5% weight

  Decision Rules:
    Risk < 0.30  → ✅ APPROVE (95% confidence)
    Risk 0.30-50 → ✅ APPROVE (75% confidence)
    Risk 0.50-70 → 🟡 MANUAL REVIEW (65% confidence)
    Risk > 0.70  → ❌ REJECT (85% confidence)
